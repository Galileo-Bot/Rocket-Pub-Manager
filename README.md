# Rocket Pub Manager

Ce bot est l'outil de prédilection de la modération sur le serveur Discord nommé Rocket Pub !
Le bot est par conséquent privé, et il n'est pas possible de l'inviter sur votre serveur.

Bot développé par Ayfri.
Serveur géré par Ayfri et Antow.

## Fonctionnalités :
Le bot comporte une multitude de fonctionnalités de modérations :

 - Système de sanctions : Il se base sur le nombre d'avertissements déjà reçu par l'utilisateur. Plus l'utilisateur est sanctionné, plus la sanction sera forte (timeout, ban...).
 - Système de vérification : Chaque publicité postée dans les salons dédiés apparaît dans un canal dédié à la modération. Il ne reste plus qu'à valider ou non la publicité selon les règles en vigueur sur le serveur.
 - Blacklist invitation : L'administration peut blacklister certaines invitations, afin d'éviter de modérer à répétition des serveurs hors ToS.
